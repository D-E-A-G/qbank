# Support

Support here means help with the source code and documentation in this repository. The [README](README.md) owns the app's status.

## Build, source, and documentation questions

Open a public [GitHub issue](https://github.com/D-E-A-G/qbank/issues) for:

- Problems following the [getting started steps](README.md#getting-started) or running the simulator build and tests.
- Questions about the code or the client-only boundary of this repository.
- Mistakes or gaps in the documentation.

Please include your Xcode and simulator runtime versions and the exact command and output when reporting a build problem. Responses are best effort; there is no service-level commitment.

The QBank server and its accounts are private; this repository cannot help with access to them.

## Security and privacy reports

Do **not** use public issues for security or privacy findings. Use the private route described in [SECURITY.md](SECURITY.md) instead.
